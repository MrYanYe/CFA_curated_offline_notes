Understanding Asset-Based Valuation Models<\/h2>\n\n\n\n

The concept of asset-based valuation models<\/b> is actually very simple. The analyst estimates the fair value of all the assets of the firm, and the fair value of all the firm\u2019s liabilities. The intrinsic value of the common stock is therefore the total value of the assets, minus all liabilities, and minus the value of the firm\u2019s preferred stock. Express this on a per share basis, and that is the intrinsic price of each share.<\/p>\n\n\n\n
