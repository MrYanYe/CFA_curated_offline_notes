Index Construction and Management: Decisions to Make | CFA Level I Equity Investments<\/h1>\n\n\n\n

In our last lesson, we learned that a market index<\/b> represents the performance of a market, using constituent securities. However, index construction and management are not that simple. An index provider needs to make five key decisions:<\/p>\n\n\n\n

    \n
  1. Target market<\/li>\n\n\n\n
  2. Selection of constituent securities<\/li>\n\n\n\n
  3. Weight of individual securities<\/li>\n\n\n\n
  4. Index rebalancing<\/li>\n\n\n\n
  5. Index reconstitution<\/li>\n<\/ol>\n\n\n\n

    Let’s examine each decision more closely.<\/p>\n\n\n\n

    1. Target Market<\/h2>\n\n\n\n

    The index provider must determine the target market the index aims to measure. This can range from broad markets like “stocks in the United States” to narrower markets like “small-cap value stocks in the United States.” Target markets may also be defined by asset class, geographic region, or other characteristics like economic sector, company size, duration, or credit quality.<\/p>\n\n\n\n

    2. Selection of Constituent Securities<\/h2>\n\n\n\n

    After identifying the target market, the index provider must select the constituent securities from the target market. While it’s possible to include all securities in the market, it often makes more economic sense to select a representative sample. Some equity indexes fix the number of stocks to be selected, like the S&P 500 and FTSE 100.<\/p>\n\n\n\n

    The selection process can be determined objectively using criteria like the number of shares outstanding, the number of shareholders, and market capitalization. Alternatively, it can be determined subjectively by a committee.<\/p>\n\n\n\n
