# CFA Level 1 Study Notes（离线站点版，2026）

本文件夹是 prepnuggets.com 学习笔记站的**完整离线拷贝**，无需网络，双击/点开 `index.html` 即可阅读。
（顶层还有 1 个单文件版 `../cfa_l1_offline_notes_all_in_one_2026.html`，可单独拷走。）

## 使用

- **电脑**：双击 `index.html`（Chrome / Edge / Safari）
- **安卓**：整个文件夹拷入手机 → Chrome 打开 `index.html`
- **iPhone/iPad**：拷入「文件」App → Safari 打开 `index.html`

## 布局

```
index.html                       主页（最外层）
<10 个栏目>/…                    每个栏目一个子目录，层级与原站一致
wp-content/ wp-json/ 等          静态资源（字体/图片/CSS/JS，勿动）
```

10 个栏目：alternative-investments / corporate-issuers / derivatives / economics / equity /
ethics / financial-statement-analysis-fsa / fixed-income / portfolio-management /
quantitative-methods，外加 `quantitative-methods/` 单页栏目。

## 已知边界

- 视频为离线占位（原站是流媒体，无法下载）
- 站内搜索/评论/登录等依赖服务器功能不可用
- 其余（正文、图表、公式、导航）全部可用
